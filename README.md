# Galactic AI V3

Galactic-AI-Prototyp mit Flask, `core/`, `backend/`, `modules/`, `urspirit/`, Weboberfläche und Bildgenerator.

## Bereinigung
Eindeutige Altlasten (`.DS_Store`, leere `.env.py`, leere Platzhalterdatei) wurden entfernt. Funktionscode, Assets und historische Projektbestandteile bleiben erhalten, bis ihre Abhängigkeiten geprüft sind.

## Architekturziel
Ein klarer Backend-Einstiegspunkt, getrennte KI-/World-/Agent-Module und eine eigenständige Weboberfläche. Duplikate werden nur entfernt, wenn Dateiinhalte und Abhängigkeiten eindeutig übereinstimmen.
